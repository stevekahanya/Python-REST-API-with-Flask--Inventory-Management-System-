# Workout Application Backend API

## Project Description
A backend REST API designed for personal trainers to track and manage workouts and exercises. Built with Flask, SQLAlchemy, and Marshmallow, it supports relational data mapping, cascade deletion, and extensive data integrity checks (Schema validations, Model validations, and Database Table Constraints).

## Requirements
* Python 3.8.13+
* Pipenv
